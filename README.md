Movespeed is set to a float, as well as the switch speed. On Start, the timer is set to the switch speed. Then, the update starts the motion upwards, being contingent on the time. Eventually, the code flips to the opposite direction once "_timer <= 0". (Side note: the switch speeds are editable, and doing so makes them flip faster, therefore following a tighter path, which is what I did to make it harder :P)
